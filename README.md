# Theory Trainer

A gamified piano theory trainer: note reading, keyboard geography, scales, chords, chord symbols (G7, C/G, B°), inversions, intervals, progressions, rhythm tapping, key signatures and notation symbols.

Mixed review works like flashcards with spaced repetition: untimed, due items first, 20 per review by default (change it in Settings). With a MIDI keyboard connected, every key you press is counted and shown as a heatmap on the Progress page.

Works with a USB MIDI keyboard in Chrome or Edge (Settings → MIDI keyboard). Progress is saved in the browser.

Everything lives in `index.html`. Replace that file to update the site.
